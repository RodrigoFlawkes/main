O sistema F3 possui diagnóstico/runner **curto e autorizado**; não estendê-lo silenciosamente para serviço de áudio sempre ativo. F4 altera volumes reais das sessões Windows e NÃO fornece PCM isolado por aplicativo. A interface e README devem continuar diferenciando isso.
